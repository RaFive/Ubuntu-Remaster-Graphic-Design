# Ubuntu-Remaster-Graphic-Design

A customized remaster of Ubuntu 24.04.5 LTS with a graphic design theme, built with [Cubic](https://github.com/PJ-Singh-001/Cubic).

## Disclaimer

This is an **unofficial** project. It is **not** affiliated with, endorsed by, or supported by Canonical Ltd. or the Ubuntu project.

It is the result of an Operating Systems course assignment: remastering Ubuntu with a theme, in this case graphic design. It is provided as is, without any warranty, and is intended for learning and personal use.
